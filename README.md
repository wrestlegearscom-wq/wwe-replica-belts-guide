# Wrestling Championship Belt Collector Guide

A static website prepared for GitHub Pages.

## Publish with GitHub Pages

1. Extract this ZIP file.
2. Upload the **contents** of this folder (not the enclosing folder) to the root of your public GitHub repository.
3. Ensure `index.html` is at the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then Save.
7. Wait for GitHub Pages to publish the site.
