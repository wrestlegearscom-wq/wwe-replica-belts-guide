# Wrestling Championship Belt Collector Guide

This version uses a **flat repository structure** so the files can be uploaded directly to the GitHub repository root.

## Publish with GitHub Pages
1. Upload all files in this ZIP to the root of your public repository.
2. If GitHub asks, replace/overwrite the existing files with the same names.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then Save.
